# EGIS Factory — 5분 데모 스크립트

시연 대상: https://seongyoru.github.io/CustomFactory/ (크롬 권장, 전체 화면 F11)

## 사전 준비 (시연 5분 전)

1. **관리자 로그인** — `admin` 카드 선택 · PIN `0000` → 튜토리얼 "건너뛰기"
2. **예열** — 리포트 → 하단 "데모 데이터 초기화"(선택) 후, **시뮬레이션 모드 ×4 배속으로 2~3분** 돌려 둔다
   → 실적·OEE·소모품 마모가 쌓여 리포트/보전 데모가 살아난다
3. 시연 직전 **운전 모드 ×1**로 되돌리고 Line_1 선택 상태로 시작
4. (선택) 다크 테마로 전환하면 3D 글로우 연출이 함께 나온다 — 취향대로

## 돌발 상황 대비

- **화면이 이상하게 쌓여 있으면** → 리포트 하단 "데모 데이터 초기화"(관리자) 후 새로고침 — 1분이면 원상 복구
- **"실설비랑 진짜 붙나요?"** → gateway/README 시연: `npm run demo-plc` + `npm run opcua` 두 줄로 가짜 PLC→게이트웨이→화면 전 경로가 로컬에서 돈다
- **"수치 근거가 뭔가요?"** → 표준시간은 애니메이션 타임라인에서 유도, 에너지는 전류×3상 근사(가정 명시), 마모율은 데모 가정 — 각 화면 ⓘ와 코드 주석에 출처가 있다
- **3분 축약판** → 0:00 → 1:15(관제) → 2:45(시뮬레이션) → 3:30(리포트)만 타고 클로징
- **저사양 노트북** → 다크 테마의 뷰 패널(우상단)에서 "글로우 효과" 끄기
